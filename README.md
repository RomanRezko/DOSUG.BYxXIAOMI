# DOSUG.BY × Xiaomi — каталог со сравнением цен

Поддомен-каталог умной техники Xiaomi со сравнением цен в магазинах-партнёрах
Беларуси. Спецпроект **DOSUG.BY × Xiaomi**.

## Возможности

- Каталог из 60 товаров Xiaomi с реальными фото и характеристиками
- Фильтры по категориям и по магазинам (мультивыбор)
- Карточка товара: галерея (стрелки + зум), характеристики, **сравнение цен**
  по 9 магазинам-партнёрам с подсветкой лучшей цены
- Тег максимальной скидки с разбивкой по магазинам
- Дизайн-система DOSUG.BY (бренд-цвета, шрифты Unbounded/Inter) —
  см. [DESIGN_SYSTEM.md](./DESIGN_SYSTEM.md)
- Ко-брендовый лендинг `/xiaomi`

## Стек

- [Next.js 16](https://nextjs.org) (App Router, Turbopack)
- React 19, TypeScript, Tailwind CSS 4

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
```

Сборка:

```bash
npm run build && npm run start
```

## Структура

- `src/app/tovary` — каталог (главная) и страница товара `/tovary/[slug]`
- `src/app/xiaomi` — коллаб-лендинг
- `src/components/shop` — карточки, галерея, сравнение цен
- `src/data` — товары, партнёры-магазины
- `public/products` — фото товаров, `public/partners` — логотипы магазинов

## Данные

Каталог наполнен товарами Xiaomi. Цены партнёров — демо-генерация; в проде
подключаются реальные фиды магазинов.
